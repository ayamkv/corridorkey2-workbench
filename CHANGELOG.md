# Changelog

## 0.0.1 — 2026-11-25

First public Windows preview, incorporating the features developed in private builds 0.3.x–0.5.x.

- Project folders with media, frame ranges, render history and saved hints.
- GPU viewer with Single, Wipe and Side-by-side comparisons and live composite despill.
- Background render queue, held jobs, progress, cancellation and reconnect.
- Scene-linear EXR and video export settings.
- SAM 2.1 Tiny click-to-mask hints with keep/remove points, a box and undo.
- Source/setup ZIP, SHA-256 checksum, licence notices and Windows checks.

Known limitations: Windows/NVIDIA only; no remote rendering or tracked roto; a complete fresh
Setup.bat installation and broader hands-on project/mask checks remain unvalidated.

Public app versions start at 0.0.1. The engine API retains version 0.5.0 for existing integrations.
